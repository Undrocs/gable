# Gable

Gable is an open-source, general-purpose programming language developed by Undrocs.

The project is in early development. Current work focuses on language design, compiler architecture, and the foundations of its toolchain.

## Status

Gable is experimental. Its syntax, features, and implementation are not yet stable.
